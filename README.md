## Mohammad Baby Shop

Responsive Bengali baby-shop storefront. Pages: Home, Shop, Product, Cart, COD Checkout, Order Success, Order Tracking, About and Admin.

Currency: BDT (৳). Payment: Cash on Delivery.

IMPORTANT: this starter is static. The demo admin and order records use browser Local Storage and are not shared or protected by authentication. Before accepting real orders, connect Supabase, add server-side order creation, secure Row Level Security and admin authentication. Never put a Supabase service-role key in browser code.

Deploy by enabling GitHub Pages for main branch, root folder, or import into Vercel as a static site.
